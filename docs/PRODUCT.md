# Product definition

MUNSHI Apply is a personal job-application intelligence system. It helps one user understand application interfaces, prepare truthful answers from verified evidence, review consequential decisions, complete legitimate repetitive interactions, and retain an auditable application history.

## Product promise

No legitimate browser-based job application is rejected merely because its platform is unknown.

## User outcome

The system should reduce repetitive effort without reducing factual accuracy or user control. Every proposed answer must expose its source. Every meaningful interaction must be verified. Every unresolved fact must remain unresolved until the user supplies it.

## Non-goals

This project is not a bulk-application spam engine, a bot-detection evasion tool, a CAPTCHA solver, an identity-verification bypass, or an AI that fabricates qualifications. Platform-specific adapters are optimizations, never the compatibility foundation.

## Release boundary

The `0.1.x` line is an observe-and-model foundation. It can discover visible controls, normalize question meaning, flag review requirements, preserve confirmed profile facts, and persist structured events. It cannot write to employer pages.

Autofill begins only after interaction verification, preview, protected-answer policies, checkpointing, and recovery are implemented and tested against the synthetic application lab.
